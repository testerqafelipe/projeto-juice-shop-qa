# Automação de Testes de API - Juice Shop & CI/CD

Projeto desenvolvido com foco em **Garantia de Qualidade (QA)** e **Integração Contínua (CI/CD)**, utilizando a aplicação vulnerável OWASP Juice Shop como laboratório prático.

## 🚀 O que foi construído
- **Testes Automatizados de API**: Criação e validação de scripts de testes funcionais usando o ecossistema Postman.
- **Pipeline de CI/CD**: Configuração de automação com **GitHub Actions** para rodar os testes automaticamente a cada alteração no código.

## 🛠️ Tecnologias Utilizadas
- **Postman / Newman** (Testes de API)
- **GitHub Actions** (CI/CD)
- **Git & GitHub** (Controle de versão)
- **Node.js & JavaScript** (Ambiente da aplicação)
